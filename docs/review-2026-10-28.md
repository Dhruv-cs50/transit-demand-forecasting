WAPE 3.21 %, bias −0.47 %; by horizon 2.6 / 2.5 / 3.3 / 3.5 / 4.4 / 2.9 % (no growth); network
total within ±2.5 % each month; per station median 2.55 %, p90 5.2 %; beats Prophet at 46/50 and
seasonal naive at 48/50 stations (paired Wilcoxon vs Prophet p ≈ 8e-21). Same spec on earlier
half-years: 6.36 % (2024-H2, coverage 80.3 %) and 4.27 % (2025-H1, coverage 91.0 %). Outliers:

Downtown Berkeley −9.75 %. No alternative model is needed.
