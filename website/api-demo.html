Forecast API — Interactive Demo

Live interface for the Bay Area Transit Demand Forecast FastAPI service. Fits SARIMA — the best model on the benchmark leaderboard — per request and returns P10/P50/P90 monthly ridership per BART station for up to 6 months. Newer versions of the API say in each response which P10/P90 band they return; the result below shows that description, or says when the API does not give one.
