| 20 | `models/chronos2/predict.py` (`main`) | `print(f"Lift : {lift.get('lift_pct', 'N/A'):+.1f}% vs typical")` applies the `:+.1f` numeric format spec to whatever `.get()` returns. Today's own reapplied fix (#13 above) added an early `return {}` from `ridership_lift()` when `typical_median` is `NaN` (e.g. a station whose relevant history is all game-days), so `lift` now frequently has no `"lift_pct"` key at all — `.get(..., 'N/A')` returns the *string* `"N/A"`, and formatting a string with `:+.1f` raises `ValueError: Unknown format code 'f' for object of type 'str'`, crashing the CLI (`python models/chronos2/predict.py --station X`) right after a successful forecast. Fixed by computing `lift_pct` separately and only applying the numeric format when it's not `None`, falling back to the literal string `"N/A"` otherwise. | Medium |
