| 22 | `Processing/feature_engineering.py` (`add_weather_features`) | `precip_3hr_sum`/`precip_6hr_sum`/`precip_24hr_sum` were computed unconditionally via `rolling(3/6/24, min_periods=1).sum()` over `precip_mm`, with no cadence guard — unlike every other hour-scale feature in this same file (`is_am_peak`/`is_pm_peak`/`is_midday`/`is_late_night`, already guarded a few lines above). At this pipeline's actual monthly cadence, each row is already a one-month aggregate, so these "hour" sums actually accumulate 3/6/24 **months** of precipitation while still being labeled and fed to the model (via `finetune.py`'s `KNOWN_FUTURE_COLS` and `ablation.py`'s `COVARIATE_GROUPS["weather"]`) as hour-scale features — silently wrong-scale training input with no crash to reveal it. Guarded behind `hour_of_day.nunique() > 1`, matching the established pattern immediately above; when absent, `finetune.py`/`ablation.py`'s `[c for c in ... if c in df.columns]` filtering already drops them safely. | High |
| 23 | `machine_learning_files/fetch_bart_od.py` (`parse_bart_od_excel`) | Iterated every sheet in the downloaded BART OD workbook with no exclusion, tagging each as its own `day_type` via `sheet_name.strip()`. Real BART OD workbooks include a `"Total Trips OD"`/`"Total Trips"` sheet alongside the Weekday/Saturday/Sunday averages — confirmed by this same repo's `transit_eda/notebooks/eda_complete.py`, which hit this exact sheet in real downloaded files and explicitly excludes it before any cross-day-type analysis (`"These are MONTHLY TOTALS, not daily averages. Removing from avg analysis."`, line 314). `merge_pipeline.py::load_transit()` then does `groupby(["period","origin","origin_name"])["riders"].sum()`, collapsing all `day_type` rows together with no such exclusion — silently adding the "Total" sheet's already-aggregated monthly figure on top of the Weekday+Saturday+Sunday sums for the same station-month, inflating the `ridership` target the entire forecasting pipeline trains against. Fixed by skipping any sheet whose name contains `"total trips"` (case-insensitive), matching the EDA script's handling. | High |
